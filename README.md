# python-stock-demo
Python实现的简易股票数据分析工具

## ✨ 项目介绍
本项目使用Python对股票历史行情数据进行读取、清洗、指标计算与可视化绘图，实现简易量化分析。

## 🛠️ 技术栈
- Python3
- pandas / numpy：数据处理
- matplotlib：行情可视化绘图

## 🚀 快速运行
1. 安装依赖包
```bash
pip install pandas numpy matplotlib
2. 执行主程序
```bash
python main.py
